# Attack of the Clankers!

Attack of The Clankers! is our Game Production (GAME-1009) culminating project. It is developed by III Studio.
Our studio consists of John, Joseph, Thomas, Cosimo, Adrian, Connor, and Nick.
The name "Attack of the Clankers" was originally just a random name when we were brainstorming ideas.
Connor ended up saying Attack of the Clankers and it ended up becoming the name of our game.
